# Five-day public launch

## Launch objective

Make LinkedIn Campaign Operator the default search result and discussion reference for people looking for a LinkedIn agent skill, LinkedIn content skill, or open-source LinkedIn growth workflow.

The launch message is consistent everywhere:

> Your LinkedIn operating system. Inside your AI agent.

Primary link: `https://github.com/sunny-chandel/linkedin-campaign-operator`

## Day 1 — Establish the source of truth

- Make the GitHub repository public and publish release `v1.0.0`.
- Publish the product website, install pages, documentation, examples, press page, and launch article.
- Add the website URL and eight discovery topics to the GitHub repository metadata.
- Pin the repository and launch post to the founder's GitHub and LinkedIn profiles.
- Submit the XML sitemap in Google Search Console and Bing Webmaster Tools.
- Publish the founder-story LinkedIn post and a short demo post two hours later.
- Ask the first 20 users to install it, run one prompt, star the repo, and share their result.

## Day 2 — Own every directory surface

- Submit to the official Claude plugin directory.
- Submit to SkillsDirectory and Claude Skills Hub.
- Post a concise build story to the OpenAI developer community/showcase.
- Prepare Product Hunt with a crisp tagline, gallery, maker comment, and install-first call to action.
- Open GitHub Discussions with `Show what you built` and `Installation help` categories.
- Answer every comment with a concrete prompt, example, or installation step.

## Day 3 — Turn the release into a story

- Send the focused press pitch to AI newsletters and developer-tool reporters.
- Pitch The Rundown AI and Ben's Bites as a free open-source agent workflow.
- Send the technical story to VentureBeat and TechCrunch tip channels.
- Publish the architecture post: why campaign state lives outside the skill.
- Publish an eight-card LinkedIn carousel, one card for each skill.

## Day 4 — Demonstrate outcomes

- Publish a 60–90 second screen recording: install → prompt → campaign state → next action.
- Share three practical use cases: solo founder, technical professional, consultant.
- Turn the strongest early user result into a quote card and short case note.
- Cross-post a technical walkthrough to dev.to, Hashnode, and relevant Reddit communities.
- Invite ten AI-agent builders to review or extend one skill.

## Day 5 — Compound the launch

- Launch on Product Hunt and coordinate maker, early-user, and community comments.
- Publish a transparent build-and-launch recap with stars, installs, visits, and user outcomes.
- Announce the next community milestone and label good-first-issue contributions.
- Create comparison and alternatives pages from real search queries found in Search Console.
- Schedule weekly release notes, one case study, and one high-intent tutorial.

## Daily command center

Track these every four hours:

- GitHub stars, forks, clones, referring domains, and release downloads;
- website users, install-button clicks, copied commands, and docs visits;
- LinkedIn impressions, profile views, saves, reposts, comments, and follower growth;
- directory approvals and referral traffic;
- media replies, newsletter placements, and creator mentions;
- installations completed and first successful campaign initializations.

Convert every question into a FAQ, every successful use into an example, and every recurring search phrase into a dedicated page.
