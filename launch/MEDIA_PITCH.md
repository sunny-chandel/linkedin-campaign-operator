# Media pitch

## Subject options

- A free, open-source LinkedIn operating system for Claude Code and Codex
- This AI agent remembers the whole LinkedIn campaign—not just the next post
- New open-source Agent Skills turn LinkedIn growth into a stateful workflow

## Pitch

Hi {{first_name}},

I built LinkedIn Campaign Operator, a free, open-source set of eight Agent Skills that runs a complete LinkedIn content and engagement workflow inside Claude Code or Codex.

The interesting technical idea is persistent campaign state. Instead of generating one post and forgetting it, the operator records verified actions, unfinished stages, analytics, experiments, and the next best work. It can resume after a new session and route research, writing, engagement planning, branding, and learning to specialized skills.

The project began as my personal 10k-follower/10k-connection system and is now configurable for any profile, timezone, niche, baseline, or growth goal. It is MIT-licensed and packaged for both Claude Code and Codex.

Repository: https://github.com/sunny-chandel/linkedin-campaign-operator

I can share a short demo, architecture notes, and early user examples. Would this fit your AI agents or creator-tools coverage?

Sunny Chandel

## Story angles

- why persistent state is the missing layer in AI social workflows;
- how an eight-skill agent system differs from a prompt pack;
- an open-source workflow built by a practitioner for his own growth campaign;
- one package targeting both Claude Code and Codex;
- transparent JSON state as an alternative to opaque automation dashboards.
