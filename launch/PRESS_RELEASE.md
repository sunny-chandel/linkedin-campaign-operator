# LinkedIn Campaign Operator launches as a free, open-source growth system for AI agents

**Eight composable Agent Skills bring research, writing, engagement planning, analytics, and persistent campaign state to Claude Code and Codex.**

August 2026 — Sunny Chandel today released LinkedIn Campaign Operator, a free and open-source operating system that lets people manage an organic LinkedIn content and engagement workflow from inside an AI coding agent.

Unlike a one-shot post generator, LinkedIn Campaign Operator keeps campaign state outside the installed skill. It can resume from the last verified action, route work across eight specialized skills, audit incomplete stages, and learn from post analytics without rewriting its own instructions.

The project includes skills for campaign orchestration, source-backed content research, post production, engagement planning, analytics learning, personal branding, GIF creative intelligence, and premium-feature routing. Its original 10,000-follower and 10,000-connection system remains the default, while public users can configure their identity, profile, timezone, niche, baselines, and growth goals.

“The useful unit is not one AI-written post. It is a campaign that remembers what happened, knows what is missing, and chooses the next useful action,” said creator Sunny Chandel.

LinkedIn Campaign Operator supports Claude Code and Codex plugin packaging, transparent JSON and JSONL state, deterministic validators and ranking scripts, and an MIT license.

The source code, installation commands, examples, and documentation are available at:

`https://github.com/sunny-chandel/linkedin-campaign-operator`
