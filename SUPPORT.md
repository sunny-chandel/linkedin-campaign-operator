# Support

- Installation and setup: use the [install guide](https://linkedin-campaign-operator.sunnychandel73.chatgpt.site/install).
- Usage questions and examples: start a GitHub Discussion.
- Reproducible bugs: open a bug report with the smallest failing sequence.
- Workflow ideas: open a feature request with an example prompt and expected artifact.

Do not include access tokens, private messages, private analytics exports, or personal campaign state in public issues.
